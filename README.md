# SharePoint Online 移管 構造デモ（匿名版）

ファイルサーバから SharePoint Online へ移管する際の**サイト／ライブラリ／フォルダ構成と権限設計**を、
実際の SharePoint Online の画面に寄せて再現したデモです。

**デモ:** https://ktamura-art.github.io/wexdemo-1/
**解説つき:** https://ktamura-art.github.io/wexdemo-1/?guide=1

---

## 設計の考え方

| 階層 | 単位 | 例 |
|---|---|---|
| 第1階層：サイト | 業務区分 | 顧客管理・営業／生産・品質／人事・労務 …（13サイト） |
| 第2階層：ライブラリ | 業務カテゴリ | 顧客資料／見積・提案／受発注 …（92ライブラリ） |
| 第3階層：フォルダ | 子項目 | 見積／提案資料／契約／クレーム … |

深いフォルダ階層の代わりに、**列（メタデータ）で絞り込む**構成にしています。

- `F分類` … 全社共通の文書管理体系
- `機密レベル` … L2〜L5
- `公開範囲` … そのライブラリを見せる部署（**部署ではなくコンテンツ単位で指定**）。92本中30本で主管部署の外へ広げています
- `年度`

## 機密レベルと権限

| レベル | 範囲 | 実装 |
|---|---|---|
| L2 | 全社共有 | 全社閲覧グループに読み取り付与 |
| L3 | 業務単位（既定） | **ライブラリごとに指定した公開範囲の部署**。主管部署は更新可、その他は閲覧のみ |
| L4 | 管理職限定 | 部署の管理職グループのみ |
| L5 | 極秘 | 案件ごとに個別作成。**対象者以外には存在も見えない** |

SharePoint には「拒否」の設定がないため、**権限のないサイト・ライブラリはリンクごと非表示**になります。
デモでもこの挙動を再現しており、鍵アイコンなどは表示されません。

## 操作

- **右上のアバターをクリック** … 表示ユーザーを切替。**11部署ぶんのペルソナ**を用意しています
  （`?user=` で直接指定：`L3`営業／`GYO`業務／`SEI`生産／`SVC`サービス／`KAN`管理本部／`GIJ`技術／`KOB`購買／`ISO`／`KEI`経理／`IT`情シス／`ALL`全社管理者）
  例：営業サイトの「顧客資料」はサービス部・業務部にも見えますが、「見積・提案」は営業部にしか見えません
- **`G` キー、または `?guide=1`** … 画面の見方を①〜⑧の番号つきで表示する解説モード
- 列見出しの `▼` … メタデータによる絞り込み

## 注意

- 本デモは**構造の検証用**であり、企業名・部署の実在の担当者名・取引先名はすべて**架空のもの**に置き換えています。
- 表示されるファイルはすべてダミーで、実データは含まれていません。
